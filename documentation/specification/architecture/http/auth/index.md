# Authentication — HTTP

Realizes [fr/auth](../../../requirements/fr/auth/index.md). Writing rules: [HTTP acceptance](../README.md).

## Routes

- Register — `POST /api/auth/register`
- Login — `POST /api/auth/login`
- Logout — `POST /api/auth/logout`
- Refresh — `GET /api/auth/refresh`
