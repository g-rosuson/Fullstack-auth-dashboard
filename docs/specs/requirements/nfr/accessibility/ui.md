# UI accessibility

How well interactive UI exposes itself to assistive technologies and the keyboard. Functional chrome behavior is under `fr/ui/`.

- **NFR-A11Y-UI-001** — Interactive UI shall expose name, role, and value to assistive technologies (WCAG 2.2 SC 4.1.2).
- **NFR-A11Y-UI-002** — Interactive UI shall be operable with a keyboard (WCAG 2.2 SC 2.1.1).
