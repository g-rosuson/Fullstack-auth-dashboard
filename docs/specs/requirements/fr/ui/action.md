# Action

Interactive controls: name, progress, submit designation, and unavailable state.

- **FR-UI-ACT-001** — An interactive control shall expose an accessible name (visible label, or an equivalent name when there is no visible label).
- **FR-UI-ACT-002** — While a primary action is in progress, the system shall indicate progress and shall not invoke the action again until it completes.
- **FR-UI-ACT-003** — An action shall not submit an enclosing form unless it is designated as the form submit action.
- **FR-UI-ACT-004** — When an action is unavailable, the system shall indicate that state through its appearance and pointer.
