# Date

A date control lets the user choose a calendar date.

- **FR-UI-DAT-001** — The system shall allow the user to choose a date from a calendar.
- **FR-UI-DAT-002** — When a date is selected, the system shall show that date on the control. When none is selected, the system shall show a placeholder.
- **FR-UI-DAT-003** — When a date control is required and empty, the system shall treat the control as invalid.
