# Form

Named forms, associated labels, validation, and named groups.

- **FR-UI-FRM-001** — A form shall expose an accessible name.
- **FR-UI-FRM-002** — Each form control shall have a visible label associated with the control.
- **FR-UI-FRM-003** — When a form control is invalid, the validation failure shall be visible with that control and the control shall be marked invalid.
- **FR-UI-FRM-004** — A named form group shall expose that name as the group’s accessible name.
