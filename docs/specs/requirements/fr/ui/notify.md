# Notify

Brief notifications report an outcome without leaving the current view, and can be dismissed.

- **FR-UI-NTF-001** — The system shall expose a brief notification whose accessible name is its title.
- **FR-UI-NTF-002** — The system shall show an optional description with a brief notification.
- **FR-UI-NTF-003** — The system shall allow the user to dismiss a brief notification.
- **FR-UI-NTF-004** — When a brief notification indicates an in-progress outcome, the system shall expose a loading status.
