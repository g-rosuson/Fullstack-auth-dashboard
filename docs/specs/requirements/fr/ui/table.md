# Table

Tabular listings expose column headers, row values, an empty state, and paging.

- **FR-UI-TBL-001** — A tabular listing shall expose each column name as a column header.
- **FR-UI-TBL-002** — A tabular listing shall present each row’s values in cells under the corresponding column headers.
- **FR-UI-TBL-003** — When a tabular listing has no rows, the system shall indicate that there are no results.
- **FR-UI-TBL-004** — When a tabular listing has more rows than one page, the system shall allow the user to move to the next page and to the previous page.
